# Security Policy

## Supported version

Security reports are welcome for the latest source on the default branch. This repository currently provides source code and a build script, not a signed or notarized installer.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not publish exploitable details or attach private media in a public issue. Include affected macOS version, app revision, and dependency versions, with personal paths and filenames removed.

Video Smart Cut invokes local third-party tools. Keep macOS, FFmpeg, Python, and MLX Whisper up to date, and review upstream security advisories for those dependencies.
